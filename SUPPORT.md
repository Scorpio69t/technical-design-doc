# Support

- Use [GitHub Discussions](https://github.com/Scorpio69t/technical-design-doc/discussions) for installation help, usage questions, and examples.
- Use [GitHub Issues](https://github.com/Scorpio69t/technical-design-doc/issues) for reproducible bugs and scoped feature proposals.
- Use [private vulnerability reporting](https://github.com/Scorpio69t/technical-design-doc/security/advisories/new) for security concerns.

When asking for help, include the client (Codex, Claude Code, Cursor, or another Agent Skills client), operating system, installation path, skill version, and the smallest prompt or document that reproduces the problem. Remove credentials and proprietary information first.
