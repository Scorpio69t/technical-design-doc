# Examples

The examples demonstrate the division of labor recommended by the skill:

- `diagrams/workspace.dsl`: one Structurizr architecture model with System Context, Container, and Deployment views;
- `diagrams/knowledge-indexing-sequence.puml`: implementation-level success/failure sequence;
- `diagrams/document-ingestion-flow.mmd`: compact asynchronous workflow;
- `diagrams/indexing-state.mmd`: durable job lifecycle;
- `sample-detailed-design.md`: short design excerpt showing how diagrams and prose work together.

The example domain is a generic private knowledge platform. It is illustrative, not a prescribed product architecture.
